# UI direction and decisions

Reading this as: a flood-segmentation workspace for portfolio reviewers, in the supplied Pinterest image-first visual language, dial ENERGY 2 / RHYTHM 2 / MOTION 1.

Antislop mode: during, selected by the owner in this conversation. The core filter is applied without installing optional companion skills or changing global agent instructions.

The source design document is a reference for visual fields and components. Its example signup flows, account screens, external commands, and marketing page sections are not application requirements.

| Decision | Purpose |
| --- | --- |
| Cream/white surfaces and dark text | Keep the satellite imagery dominant while matching the supplied reference. |
| `#e60023` on the segmentation action | Identify the one action that runs the model, rather than distributing emphasis across the page. |
| Self-hosted Inter | Use the reference's permitted open-source substitute for proprietary Pin Sans, with no runtime font network request. |
| Large two-line title and asymmetric workspace | Explain the two-input task and give the image more space than the controls. |
| 16px standard and 32px large corners | Preserve the reference's shape vocabulary without making every control a pill. |
| Flat image cards, no decorative shadows | Let actual image contrast supply depth. |
| Natural square satellite previews | Preserve geography and raster proportions; do not manufacture varied masonry ratios by cropping scientific imagery. |
| Tight sample-gallery gutters | Follow the reference's image-discovery composition using the real 15 supplied tiles. |
| Pills only for tile labels and download affordances | Attach functional identity/actions directly to the sample imagery. |
| Blue overlay and explicit legend | Distinguish model output from natural-colour imagery; this is a data colour, not a second primary UI action. |
| Minimal motion | Indicate real processing and control state without distracting from image comparison. |
| Fixed light theme | Follow the owner's explicit light Pinterest reference; no theme toggle or untested second theme is shipped. |
| Text-only product identity | Use the project's name without inventing an unrequested logo or mascot. |

Navigation targets the actual Workspace, Samples, and Model sections. No signup, testimonials, promotional claims, fake statistics, FAQ, or placeholder destinations are included. Historical metrics come from the selected checkpoint's recorded evaluation. Image gallery assets come directly from the bundled TIFFs.
